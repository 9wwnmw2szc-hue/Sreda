# Страница заявок

/leads теперь показывает обращения выбранного бизнеса, фильтры Все/Новые/В работе/Закрытые,
обновление, карточку с именем, площадкой, телефоном, сообщением, датой и изменением статуса.
PATCH сохраняет статус на сервере; при фильтре запись исчезает из списка, если перестала ему соответствовать.
Сообщение об успехе появляется после ответа API. Повторное сохранение блокируется на время запроса.
Ошибка 401/403/404 скрывает данные. При переключении бизнеса/роли список размонтируется,
запоздалые ответы загрузки не меняют данные другого бизнеса. Демо показывает данные без сохранения статусов.

Список фильтруется сервером, по 100 записей. Кнопка «Показать ещё» передаёт курсор createdAt|id.
Сортировка по времени с точностью миллисекунд и UUID совпадает с точностью JSON Date, включая
исходные PostgreSQL timestamp с микросекундами. Новые обращения не сдвигают следующую страницу.
Это не неизменяемый снимок: обновление перечитывает список; параллельное изменение статуса другим
участником может изменить состав фильтра. При одновременном сохранении статуса действует последняя запись.
Для большого объёма перед production следует измерить запрос и подобрать индекс для выражения даты.

Тесты: 105 записей с одинаковым временем и микросекундами без пропусков/повторов, новое обращение между
страницами, фильтр после изменения статуса, неверный курсор, scoped client GET/PATCH, права оператора,
отзыв членства. HTTPS: /leads, PATCH со штатным Origin и отказ чужому, фильтр и курсор.
Набор 41 тест: 36 локальных, 5 дополнительных конкурентных PostgreSQL. Lint/build/typecheck обязательны.

Браузер повторно заблокировал http://terminal.local:4175/dashboard: ERR_BLOCKED_BY_CLIENT.
Свежие скриншоты и ручная проверка формы не выполнены; standalone браузер и сетевые обходы не использовались.
Сохранённые исторические скриншоты Dashboard/каталога/мастера/создания бизнеса не доказывают готовность новой страницы.
Перед визуальным принятием: desktop/mobile, клавиатура/модальное окно, длинные сообщения, загрузка/ошибки,
переключение бизнеса, сохранение и фильтры. Новый хостинг отложен пользователем.
