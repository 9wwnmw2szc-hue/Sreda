## Визуальный стандарт

| Область | Решение |
|---|---|
| Основной шрифт | Manrope, поддержка кириллицы |
| Основной текст | --text-primary, вторичный --text-secondary; не добавлять новые оттенки для одинаковых ролей |
| Действие | --accent; зелёная .button--primary |
| Вторичное действие | .button--outline; текстовая ссылка для перехода в раздел |
| Кнопка | Общая .button: высота от 46 px; мобильные CTA от 44 px |
| Иконка-кнопка | .icon-button: область нажатия минимум 44×44 px; доступное имя обязательно |
| Поля | Нативные input/select, связанная подпись, видимый фокус |
| Карточка | Общая .panel; индивидуальные отступы только для конкретной композиции |
| Модальное окно | DetailDialog: закрытие кнопкой/Escape, фокус внутри, возврат на исходный элемент |
| Подключённые решения | Статусы из данных бизнеса; цвет модуля обозначает тип решения, не состояние подключения |
| Анимация | Небольшой hover; поддержка reduced-motion; без непрерывного движения декора |
| Центральная сцена | Единый frame и config/scene.ts; декор не является интерактивным контролом |

## Контракт состояний

- Loading: нейтральные LoadingPanel, а не «нет заявок» или «нет подписки» до ответа источника данных.
- Empty: после успешной загрузки показываем понятное объяснение отсутствия данных.
- Error: сообщение и повторная загрузка; не оставляем на экране прежние данные под новым бизнесом.
- Success: состояние и доступные действия соответствуют выбранному бизнесу.
- Поиск: только загруженные решения/последние события; Escape очищает запрос; смена бизнеса и открытие результата очищают поиск.
- Мобильный список: «Последние заявки», поскольку содержит несколько статусов. Счётчик относится к новым среди загруженных последних заявок.
- Предпросмотр поста показывает заголовок и excerpt. Подключения, оплата и публикация обозначены как демонстрация.

## Проверка этапа

11 сентября 2026: typecheck, lint и build пройдены. Поиск «десерты» находит публикацию; Escape очищает поиск. Предпросмотр показывает excerpt, Escape закрывает окно и возвращает фокус на исходную публикацию. Дополнительно проверены искусственная задержка mock-ответа и ошибка billing-сервиса. Кнопка повторной загрузки после восстановления billing возвращает Dashboard. Временные изменения mock-сервисов восстановлены; в production-код не включены переключатели тестовых ошибок.

Обязательные размеры: 1440, 1280, 900, 390. Режим проверки — реальный браузер и iframe с указанной шириной; снимки масштабируются под окно браузера. На узком viewport классическая полоса прокрутки уменьшает ширину контента на 15 px.

Перед слиянием: npm run typecheck, npm run lint, npm run build, проверка адаптива, поиска, модальных окон, переключения бизнеса, загрузки и ошибки. Пользователь разрешил продолжать план и сливать проверенные этапы без повторного подтверждения (11 сентября 2026). Этап 1 не означает готовность backend или запуск сервиса.
